# 单词小屋 · 农场学习乐园

纯前端网页应用，无需后端，双击 `index.html` 即可用。学习数据存在浏览器本地（localStorage），可离线使用，可添加到手机/平板主屏当 App。

界面由 **Kenney Tiny Farm** 像素素材包搭建（CC0 公共领域），整体是"农场学习乐园"：田地（学新词）、打谷场（闯关）、集市（商店）、我的农场（成长）。

## 文件结构

| 文件 | 作用 | 什么时候改它 |
|---|---|---|
| `index.html` | 入口，只负责挂载 | 基本不用改 |
| `style.css` | **全部视觉**（颜色、圆角、字号、间距、场景分层） | 换素材包时改这里 |
| `app.js` | 全部逻辑 + 场景/导航/卡片的图块拼装 | 改功能或换场景时 |
| `words.js` | 词库（247 条课本词，自动生成） | 不要手改，用构建脚本重生成 |
| `assets/tinyfarm/` | 132 个 16×16 图块（`tile_0000.png`–`tile_0131.png`） | 换素材包时整体替换 |
| `assets/tex/` | 从图块派生的无缝材质：草地 / 木纹 / 泥土 / 草沿 | 由 `tools/make-textures.py` 生成 |
| `assets/sprites.css` | 132 个 `.sp-XXXX` 精灵类 | 由 `tools/gen-sprites.py` 生成 |
| `assets/fonts/kenpixel.ttf` | Kenney 像素字体 | 一般不动 |

| `tools/build-pep-words.js` | 把两册词表合成 `words.js`，并算拼读分级 | 加册 / 改分级规则时 |
| `tools/legacy-map.js` | 旧词库（1464 词）序号→单词映射 | 只给老存档迁移用，迁移完可删 |
| `tools/build-words.js` | 旧的 ECDICT 建库脚本（当前不用） | 仅作存档，留着重跑旧词库 |
| `tools/make-textures.py` | 图块派生无缝材质 | 换素材包后跑一次 |
| `tools/gen-sprites.py` | 生成精灵类 | 换素材包后跑一次 |

## 素材使用规则

这几点决定了像素风看起来是"干净"还是"糊"：

1. **只用整数倍尺寸**：16×16 的图块只能显示成 16 / 32 / 48 / 64 / 80 / 96 / 112 px，其他尺寸会出现半个像素，边缘发虚。`app.js` 里 `spr(tile, size)` 的 `size` 必须是 16 的倍数。
2. **场景带分三层**（`sceneBand()`）：远处树线 → 草地上散置物件 → 土垄里的作物和人物。每层用 flex 均匀分布，层与层靠 `bottom` 和左右缩进错开，同层元素不会互相压住。
3. **文字永远优先**：单词、释义、拼写字母、按钮都不垫图块、不加纹理，只用素材做边框和背景。装饰全部 `aria-hidden`。
4. **材质从图块派生**：草地、木纹、泥土都是从原图块裁剪 + 边缘像素修补得来的无缝纹理，没有新造像素，所以色调和素材完全一致。

## 换成别的素材包

1. 把新图块放进 `assets/tinyfarm/`（保持 `tile_XXXX.png` 命名），跑 `python tools/gen-sprites.py` 和 `python tools/make-textures.py`
2. 改 `app.js` 顶部的 `TILE` 常量——它是"语义 → 图块编号"的映射表，界面里所有装饰都通过它取图，改这一处就能整体换装
3. 改 `style.css` 顶部 `:root` 里的色板（现在的颜色是从 Tiny Farm 图块里采样出来的）

## 两个小朋友怎么用

一开始就内置两个档案（默认叫「席振坤」「席昕玥」，可改）：

- **切换**：点顶部横幅左边的头像 → 选人。学过的词、金币、经验、错词本各记各的，互不影响。
- **改名换头像**：家长中心 → 小朋友档案。头像从素材包里的 6 个像素角色里选。
- **看对方**：底部「对决」页把两个人的 6 项数据并排列出来，领先一侧标金色；点对方的卡片可以直接切过去，对比视角也跟着调转，不用回主页。
- **首页随时瞄一眼**：今日页金币卡片下面有一条对方战况，写着对方金币、学过的词数、今天背了几个。

数据键是 `db.profiles.a1` / `a2`，切换只改 `db.active`。

> 切换不需要密码——孩子自己点两下就能换人。如果担心互相乱花金币，可以在家长中心盯一下兑换记录，或者跟孩子约定好。

## 词库数据来源

词库现在**就是课本词表本身**，不再是词典里捞出来的词。

- 词表：人教PEP 课本 Appendix 2「单元词汇表」原页（家长拍摄），`tools/pep-4a.json` + `tools/pep-6a.json`
- 音标、中文释义、星标：**全部照抄课本原文**，不补写、不改写
- 星标（`star`）= 课本标注 `*` 的词，即《义务教育英语课程标准（2022年版）》二级词
- 拼读分级 `lv` 与字母切分 `seg`：由 `tools/build-pep-words.js` 按固定规则计算

重新生成词库：

```bash
node tools/build-pep-words.js
```

脚本会自检：切分拼起来必须等于原词、音标格式合法、释义含中文、同形词已合并。

### 为什么不再用 ECDICT

旧词库按 ECDICT 的中考标签选了 1464 词，其中只有 35% 出现在小学课本里，另有 947 个中考词对小学生超纲。
对比报告见 `词库对比报告.md`。

### 几个数据上的约定

- `sp: true` 表示纯字母词，用字母格拼写；`sp: false` 是词组（look after / stay up）和带连字符的词（T-shirt），**改用「中文→英文」四选一**作答
- 词组的干扰项只从**同一册**里取，并且优先取同类（词组配词组），不然选项一眼就能按形状排除
- 课本对词组本来就不标音标，所以 `p` 可能为空字符串，这是照抄原样，不是缺数据
- 同形词（cook 烹饪/厨师、cold 冷的/感冒、run 跑/运转…）只建一条，用 `also` 记录它所属的其他单元，避免学习记录分裂
- 课本里有 `PE`、`Ms`、`Chinese` 这类带大写字母的词，切分按小写做，显示时还原原词大小写

## 分级规则（L1–L8）

| 等级 | 特征 | 例 |
|---|---|---|
| L1 | 单音节闭音节（辅音+元音+辅音） | get, big, run |
| L2 | 单音节，含辅音组合 | jump, fish, desk |
| L3 | 单音节，含元音字母组合 | book, rain, night |
| L4 | 单音节，开音节或词末不发音 e | go, make, time |
| L5 | 单音节，含 r 控制元音 | car, bird, fork |
| L6 | 双音节，简单结构 | happy, pencil |
| L7 | 双音节，含元音组合或词末 e | teacher, birthday |
| L8 | 三音节及以上 | elephant, banana |

## 拼读分色说明

颜色代表的是**拼写类型**，不是发音判断：

- 红 = 单个元音字母，青绿 = 元音字母组合
- 灰蓝 = 单个辅音，紫 = 辅音字母组合
- 橙 = 词末 e（前接"元音+辅音"结构），浅灰 = 其他不发音的 e

所以它是可以在任何单词上验证的，不存在"标错发音"的问题。

## 自测（改完代码先跑这个）

`tools/selftest.html` 是自动化验收页，直接在浏览器里打开就会自己跑完，右上角显示结果。

它会先把存档键重定向到 `wordfun.v2.selftest`，所以**在你自己常用的浏览器里打开也不会动到真实的学习数据**。

- 打开 `tools/selftest.html#p1`：跑 189 项检查（含老存档迁移、按册隔离、词组四选一），覆盖词库体检、17 个界面渲染、拼错/拼对反馈、连点防重、复习调度、闯关结算、金币不足拦截、兑换、家长中心、双档案隔离与切换、改名换头像、对决页数据、跨天重置、清空数据。
- 然后**关掉浏览器重新打开** `tools/selftest.html#p2`：新进程重新读存档，比对金币、经验、学习词数、错词、设置是否原样还在（这一步就是测"刷新后进度会不会丢"）。
- 命令行跑法（无头，不弹窗）：

```bash
EDGE="/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe"
"$EDGE" --headless=new --virtual-time-budget=90000 --dump-dom \
  "file:///<项目绝对路径>/tools/selftest.html#p1" | grep -o 'PASS\|FAIL' | sort | uniq -c
```

脚本会顺带捕获运行期未捕获异常，最后一行会写明「失败 N 项」和异常列表，全绿应该是 `失败 0 项 / 未捕获异常：无`。

## 已知限制

- 词库目前只收了 **四年级上册 + 六年级上册** 两册（孩子当前在读的两册）。三年级、五年级和下册要等课本词表补齐
- 发音用系统自带语音（Web Speech API），音质取决于设备；个别老安卓机型语音包不全
- 数据只存本机浏览器，清缓存会丢进度；要跨设备同步需要接后端
